# ⚡ THE WEIRD WEB LAB

### _A playground for the beautifully weird side of the web._

A creative, interactive web experiment built to explore motion, color, particles, and playful user interaction — all wrapped in a dark, futuristic interface.

**THE WEIRD WEB LAB** is more than a static webpage. It's a little digital playground where users can experiment with visual effects, customize the atmosphere, and make the experience their own.

> _Normal is overrated. Let's make the web weird._

---

## ✦ Features

- **Interactive Particle Universe** — A dynamic background filled with moving particles and connecting lines.
- **Live Visual Controls** — Experiment with particle density, movement speed, connection distance, and pulse intensity.
- **Custom Accent Colors** — Change the visual atmosphere with different accent colors.
- **Click Pulse Effects** — Add playful visual reactions to user interaction.
- **Quick Presets** — Switch between different visual moods with a single click.
- **Surprise Interaction** — Discover unexpected details throughout the experience.
- **Responsive Interface** — Designed with a focus on a clean and engaging visual experience.
- **Lightweight by Design** — Built with vanilla web technologies, without requiring a large framework.

## 🧪 Experiments & Controls

The Lab is designed to encourage experimentation.

| Control | What it does |
| --- | --- |
| Density | Adjusts the number of particles |
| Speed | Changes particle movement |
| Connections | Controls the distance between connected particles |
| Pulse | Adjusts the intensity of click interactions |
| Accent | Changes the interface's accent color |
| Presets | Applies predefined visual configurations |
